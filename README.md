# **Sistema de Gerenciamento de Academia**

* Gere a operação de uma academia (planos, membros, funcionários, aulas e assinaturas) com acesso por login e perfis de gerente, recepcionista, instrutor e membro.
* Exige assinatura ativa para frequentar e participar em aulas, bloqueando contas desativadas ou assinaturas vencidas.
* Gere o ciclo das assinaturas (ativas, vencidas conforme prazo de pagamento sem quitação, reativadas após pagamento e canceladas com data de término), além das permissões específicas de cada perfil.
